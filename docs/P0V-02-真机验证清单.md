## P0V-02：核心必过——Locator 恢复（三场景）

**通用前置**：打开一本书 → 翻到一个**可辨识的位置**（记住：当前章节、控制条显示的进度百分比、当前段落开头几个字）。

### 场景 1：旋转（配置变更）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 翻到某章，记下进度%（如 23%）和段首文字 | 正文显示，顶栏显示「进度 23%」 |
| 2 | 旋转屏幕（横↔竖） | Activity 重建，正文回到**同一位置** |
| 3 | 检查进度与段落 | 仍 23%，同一段落可见 ✅ |
| 4 | 重复 2~3 三次 | 每次都恢复到同一位置 |

### 场景 2：后台被杀

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 翻到某章，记下进度%（如 45%）和段首 | 正文显示 |
| 2 | 按 Home 回桌面 | App 进后台 |
| 3 | 开「不保留活动」（开发者选项）后直接切回；**或**不开此选项、打开几个占内存 App 再切回 | Activity 被系统重建 |
| 4 | 回到 App | loading 遮罩闪现 → 正文恢复 |
| 5 | 检查段落与进度 | 同一段落，45% ✅ |

### 场景 3：强杀

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 翻到某章，记下进度%（如 68%）和段首 | 正文显示 |
| 2 | 从最近任务列表划掉 App，**或** 设置→应用→强制停止 | 进程被杀 |
| 3 | 重新点图标启动 | 欢迎页（或如保留导航栈则直接回阅读页） |
| 4 | 重新打开同一本书 | loading → 正文恢复 |
| 5 | 检查段落与进度 | 同一段落，68% ✅ |

> **判定**：三场景全部恢复到正确位置 + 进度一致 = P0V-02 Locator 恢复通过。
> 原理：Locator 存 DataStore（防抖 1.5s + onStop 强制 flush），进程重建后从 SavedState/route 拿 contentHash → 重新 open → 读 Locator 作 initialLocator。

## 字号 / 主题保位

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开书，翻到某页 | 默认字号、日间主题 |
| 2 | 点底栏 A+ 三次 | 字号增大，实时生效，位置不跳 |
| 3 | 点「夜」 | 背景变黑、文字变白，**无白屏闪烁** |
| 4 | 点「黄」 | 护眼米黄背景 |
| 5 | 旋转屏幕 | 字号与主题保留 |

> Phase 0 偏好为内存态——强杀重开后回到默认是**预期行为**（跨进程持久化留 Phase 1 TYPE）。

## 高亮 Decoration

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开书，翻到有正文页 | 正常显示 |
| 2 | 点底栏「加高亮」（填充图标） | 当前位置出现黄色高亮块，计数 +1 |
| 3 | 翻页再翻回 | 高亮仍在 |
| 4 | 旋转 | 高亮保留 |
| 5 | 点「清」 | 高亮清除，计数归 0 |
